# LittleSteps — User Stories (V1)

## Epic 1: Journey & Profile Management
- **US1.1**: As a parent, I want to create a Child Journey by entering my child's name, birthday, and an optional avatar, so that I have a dedicated space for their memories.
- **US1.2**: As a parent, I want to edit my child's profile, so that I can update their photo or fix a typo in their name or birthday.

## Epic 2: Milestone & Timeline Management
- **US2.1**: As a parent, I want to view my child's milestones in a chronological timeline based on when they occurred, so that I can easily see their growth story.
- **US2.2**: As a parent, I want to add a milestone (from a suggestion or a custom one), specifying what happened and when, so that I can mark an important event.
- **US2.3**: As a parent, I want to edit a milestone's title, description, or date, so that I can correct information without recreating it.
- **US2.4**: As a parent, I want to delete a milestone, so that I can remove events I no longer want to keep in the journey.

## Epic 3: Memories & Media
- **US3.1**: As a parent, I want to add a memory to a milestone, describing the detailed story of that moment.
- **US3.2**: As a parent, I want to edit a memory's text or date, so that I can refine the story.
- **US3.3**: As a parent, I want to attach multiple photos and videos to a memory, so that I can visually remember the moment.
- **US3.4**: As a parent, I want to reorder photos and videos within a memory, so that they tell the story in the right sequence.
- **US3.5**: As a parent, I want to delete a photo or video, so that I can remove bad shots or duplicates.
- **US3.6**: As a parent, I want to delete a memory (which automatically removes its media), without deleting the whole milestone.
